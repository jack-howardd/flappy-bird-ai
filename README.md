# flappy-bird-ai
Created a generational AI that learns how to play Flappy Bird without using any built-in ML libraries.

## Features

- Neural network implemented without TensorFlow or PyTorch
- Evolution/training system for improving agents over time
- Flappy Bird environment written in Python

## Technologies

- Python
- NumPy

## Output

- max.txt and mean.txt describe the performance of the latest model
